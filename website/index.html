    Security

    Connected doesn't mean exposed.

    Before a browser can access your shared content, it has to get past a PIN — the one shown only on your phone.

    PIN · 4827
    Enter PIN → Authenticated

    Tip: share on networks you trust, and stop sharing when you're done.

    Privacy control

    You decide what the browser can see.

    When you only want to receive a file, you can switch off browser access to your phone's contents — so the other person can send to you without browsing your files.

    Person A: “Send me that file.”

    Person B: “Sure — but you don't need access to my phone.”

    FAQ

    Questions, answered.

    Does the other device need BlinkDrop?

    No. It only needs a web browser.

    Does BlinkDrop use cloud storage?

    No. File transfers are performed over the local network.

    Do I need an account?

    No.

    Do both devices need to be on the same Wi-Fi?

    Yes, the devices need to be able to reach each other over the local network.

    Is the connection protected?

    BlinkDrop uses a PIN authentication step before the browser can access shared phone content.

    Can I send files back to my phone?

    Yes.

    Can I prevent the browser from browsing my phone?

    Yes. BlinkDrop provides a privacy control for browser access to phone content.
